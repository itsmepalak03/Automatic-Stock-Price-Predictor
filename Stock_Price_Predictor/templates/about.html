Automatic Stock Price Predictor

A full-stack web application built with Python (Flask) that fetches live NSE stock data, applies machine learning algorithms to predict future stock prices, and presents results through professional-grade interactive Plotly charts including candlestick visualisations.

The project demonstrates end-to-end data engineering, feature engineering with technical indicators (RSI, MACD, Bollinger Bands, SMA, EMA), supervised ML prediction, and production-quality web development.

Machine Learning Model — How It Works
1. Feature Engineering
The model extracts 15+ technical features from OHLCV data: Simple Moving Averages (SMA-5, SMA-10, SMA-20), Exponential Moving Averages (EMA-12, EMA-26), RSI (14-day), MACD and Signal line, Bollinger Band width, 1-day and 5-day price returns, and 10-day rolling volatility.
2. Model Architecture
scikit-learn's LinearRegression with MinMaxScaler normalisation. Features and target are independently scaled to [0,1] to prevent numerical dominance by high-magnitude features like price and volume.
3. Walk-Forward Prediction
For future days, the model uses a walk-forward approach: each predicted price is fed back as input to compute the next day's technical indicators, which are then used to predict the next price. This chains predictions across 10 days.
4. Signal Generation
Buy/Sell signals are generated by comparing each predicted price against the current LTP: >+2% = STRONG BUY, +0.5% to +2% = BUY, −0.5% to +0.5% = HOLD, −2% to −0.5% = SELL, <−2% = STRONG SELL.
