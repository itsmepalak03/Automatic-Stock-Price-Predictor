# Automatic-Stock-Price-Pridictor

A web application built with Flask that provides live stock market information, historical data visualization, and stock price prediction using machine learning.

## Features

- Live stock market data
- Historical stock price charts
- Stock search functionality
- Machine learning based stock prediction
- User-friendly web interface
- Data analysis using Pandas and NumPy

## Technologies Used

### Backend
- Python
- Flask

### Data Processing
- Pandas
- NumPy

### Machine Learning
- Scikit-Learn

### Stock Data
- yFinance

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

---

## Stock Data Source

This project uses Yahoo Finance data through the yFinance Python library.

Data availability depends on Yahoo Finance services.

---

## Notes

- Internet connection is required for fetching stock data.
- Prediction results are generated using machine learning models and should not be considered financial advice.
- This project is intended for learning and educational purposes.
